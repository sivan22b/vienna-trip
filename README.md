# וינה בחג המולד 🎄

אפליקציית טיול פשוטה (PWA) לווינה, 21-30 בדצמבר 2026. HTML/CSS/JS בלבד, בלי שרת.

- `data.json`: רשימת המקומות ההתחלתית
- השינויים (הוספה, עריכה, "ביקרנו") נשמרים בטלפון. מעבירים בין טלפונים עם ייצוא/ייבוא בהגדרות ⚙️
- מפה: Leaflet + OpenStreetMap. מזג אוויר: Open-Meteo
- עובד אופליין אחרי הפתיחה הראשונה

עדכון הרשימה ההתחלתית: מחליפים את `data.json` ומעלים את `VERSION` ב-`sw.js`.
